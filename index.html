Tools Built

I've built a suite of Python tools that run across my client accounts — each one automates something that would otherwise take hours of manual analysis per week.

  • Tracking Audit Checks GTM containers, Google Ads tags, GA4 purchase events, Enhanced Conversions, and Consent Mode v2 across all accounts. Flags critical issues with a prioritised fix plan.
  • Weekly Performance Pulls Google Ads data, runs a search term audit for wasted spend, generates a campaign deep-dive, and posts action items to Monday.com automatically.
  • Feed Health Audits Merchant Center approvals and Shopify product data in one run. Proposes title fixes using a keyword-first formula and applies approved changes via the Shopify API.
  • SEO Audit Full Shopify on-page analysis — title tags, meta descriptions, image alt text, thin content, orphan products — combined with Core Web Vitals and Search Console data.
  • Search Console Weekly analysis of ranking movements: quick wins at positions 5–15, CTR gaps versus position benchmarks, declining queries, and new entries to the top 20.
