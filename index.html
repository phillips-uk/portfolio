Tools Built

A suite of Python tools that run across client accounts — each one automates something that would otherwise take hours of manual analysis per week.

  • Tracking Audit Checks GTM containers, Google Ads tags, GA4 purchase events, Enhanced Conversions, and Consent Mode v2 across all accounts. Flags critical issues with a prioritised fix plan and posts action items to project management automatically.
  • Weekly Performance Pulls Google Ads data, runs a search term audit for wasted spend, generates a campaign deep-dive, and creates project management action items — all in one run, every Monday.
  • Feed Health Audits Merchant Center approval rates and Shopify product data in one pass. Proposes Shopping title fixes using a keyword-first formula and applies approved changes via the Shopify API.
  • SEO Audit Full Shopify on-page audit — title tags, meta descriptions, image alt text, thin content, orphan products — combined with Core Web Vitals via PageSpeed Insights and Search Console data.
  • Search Console Weekly analysis of ranking movement: quick wins at positions 5–15, CTR gaps versus position benchmarks, declining queries to watch, and new entries to the top 20.
